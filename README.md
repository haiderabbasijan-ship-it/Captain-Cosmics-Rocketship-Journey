# 🚀 Captain Cosmic

## Overview

**Captain Cosmic** is a 3D educational space adventure game developed as part of my **Concurrent Design** university project at the University of Leicester.

The game combines exploration, arcade-style gameplay and educational elements. Players take on the role of a space explorer travelling through a Jupiter-themed environment, where they must shoot asteroids, collect lost data and complete their mission while learning interesting facts along the way.

The project was developed collaboratively using an organised sprint-based workflow, with the team working together to design, develop and refine a fully functional Minimum Viable Product (MVP).

## 🎮 Gameplay

Players navigate through a 3D space environment surrounding Jupiter while completing their mission.

The core gameplay involves:

* ☄️ Shooting and destroying asteroids
* 💾 Collecting lost data scattered throughout the environment
* 🪐 Exploring a Jupiter-themed 3D level
* 🧠 Learning educational facts when collecting data
* 🤖 Interacting with an AI-style avatar
* 🏆 Building a score throughout the mission
* 🎬 Experiencing cutscenes and narrative elements
* 🔊 Music and sound effects throughout gameplay
* ✅ Completing the mission and receiving a final score

## ✨ Key Features

### 3D Gameplay Environment

A fully playable 3D environment designed around Jupiter, providing an immersive setting for the player's mission.

### Asteroid Combat

Players can shoot incoming asteroids as part of the main gameplay loop, creating an arcade-style challenge.

### Educational Data Collection

Lost data can be collected throughout the level. When data is collected, the game provides educational information, adding a learning element to the gameplay.

### Scoring System

A scoring system tracks the player's progress and provides a final score when the mission is completed.

### Narrative & Presentation

The game includes a main menu, controls and credits screens, cutscenes, music, sound effects and a mission success screen to create a complete gameplay experience.

## 🏆 Project Outcome

The completed game delivered a fully functional playable MVP featuring a complete main menu, 3D gameplay, asteroid combat, data collection, educational interactions, scoring, music, sound effects, cutscenes and a mission completion sequence.

The project received particularly positive feedback for its **adventure-style gameplay**, which was compared to a theme park experience, as well as its **recognisable character and distinctive identity**.
